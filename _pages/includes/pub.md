# Research

<p class="section-intro">I use papers and projects as a way to make the same loop reproducible: define the failure, choose a mechanism, test an intervention, and report the boundary.</p>

<div class="research-list">
  <article>
    <p class="eyebrow">Dexterous hand representation</p>
    <h3>UniDexTok: A Unified Dexterous Hand Tokenizer from Real Data</h3>
    <p>Built and evaluated a shared 22-dimensional representation across hand embodiments. With 4,528 frames, about 6.2% of the target data, few-shot adaptation reduced reconstruction error and transferred to unseen hands.</p>
  </article>
  <article>
    <p class="eyebrow">Vision-and-language navigation</p>
    <h3>ESVNav: Evidence-Based Stop Verification for Continuous Environments</h3>
    <p>Reframed a high-scoring STOP action as a proposal that still needs verification. A plug-in stop verifier checks the visited trajectory before committing to a final location.</p>
  </article>
  <article>
    <p class="eyebrow">Personal project</p>
    <h3>OpenVLA drawer manipulation</h3>
    <p>Fine-tuned OpenVLA-7B with LoRA on 128 real-robot trajectories and connected the policy to a Unitree Go2 + D1 setup. The fixed-scene drawer task reached 72% success.</p>
  </article>
</div>
